# Jeongsu Tech

기술 학습 문서를 모은 정적 사이트입니다. AI 사용방법, Git 사용방법, 제품 기획과 운영, AI Map을 제공합니다.

- 배포: https://linjingzhu.github.io/tech-jeongsu/
- GitHub Pages는 기존 `stable` 브랜치의 루트 파일을 배포합니다. 별도 빌드가 필요하지 않습니다.
- 상단의 한 / EN 버튼은 탐색 메뉴와 본문을 함께 전환하며 선택을 브라우저에 저장합니다.
- 헤더 중앙의 검색창은 현재 언어의 문서 제목·본문·코드와 AI Map 도구·가이드·뉴스를 검색합니다. 일치하는 모든 결과를 스크롤해 볼 수 있으며, 문서 결과는 해당 섹션으로, 외부 자료는 새 탭으로 연결됩니다. Ctrl/Cmd+K로 검색창에 이동하고 방향키·Enter·Escape로 조작합니다.
- 왼쪽 내부 목차는 현재 문서의 제목으로 이동합니다. 모바일에서는 상단 목차 버튼으로 엽니다.
- 오른쪽 눈금은 문서 길이에 따라 표시되며 현재 위치를 강조합니다. 클릭이나 방향키로 이동할 수 있습니다. 퍼센트는 표시하지 않습니다.
- 코드 블록은 복사를 지원하고, 표와 다이어그램은 좁은 화면에서도 읽을 수 있도록 표시합니다.

## 콘텐츠 수정

한국어 Markdown은 `content/`, 영문은 동일한 경로의 `content/en/`에 있습니다. 제목 계층과 Mermaid 노드·연결은 두 언어에서 동일하게 유지합니다. 문서 목록은 `assets/app.js`의 `DOCS`, 번역된 메뉴와 인터페이스 문구는 `assets/i18n.js`에서 관리합니다.

AI Map 원본은 `assets/ai-map-data.js`, 영문은 `assets/ai-map-data.en.js`입니다. 두 파일의 ID, URL, 날짜, 순서와 필드 구조를 함께 유지해야 합니다. 번역이 가격·기능 정보의 최신성을 보증하지는 않습니다.

문서 주소는 기존 `#content/…` 형식을 유지합니다. 목차 주소는 `::section-N`을 덧붙이므로 제목 순서를 바꾸면 해당 섹션 링크도 확인하십시오.

## 로컬 확인

저장소 루트에서 정적 HTTP 서버를 열고 브라우저로 접속합니다. 예: `python -m http.server 4173`. `file://`로 열면 Markdown을 가져올 수 없습니다.

자동 검증: `node --test tests/content.test.cjs tests/search.test.cjs`. 모든 문서의 한·영 대응, AI Map 항목 보존, 로컬 자산, Mermaid 연결과 검색 결과·섹션 연결을 확인합니다. 화면 변경 후에는 별도로 데스크톱·태블릿·모바일에서 메뉴, 목차, 검색, 언어 전환을 확인합니다.

검색은 서버로 검색어를 보내지 않습니다. 첫 검색 때 현재 언어의 Markdown 문서를 최대 네 개씩 불러와 브라우저 메모리에 색인을 만들며, 언어별로 재사용합니다. 문서 일부를 불러오지 못하면 검색 결과에 안내와 재시도 버튼을 표시합니다.

실행 라이브러리는 버전을 고정해 `assets/vendor/`에 보관합니다. 폰트는 Google Fonts의 Noto Sans KR와 JetBrains Mono를 사용하며 시스템 폰트를 대체 글꼴로 둡니다.

사이트 스타일이나 동작 파일을 배포할 때는 `index.html`의 해당 자산 URL에 붙은 `v` 값도 갱신합니다. GitHub Pages의 캐시가 이전 CSS와 JavaScript를 유지하는 동안에도 같은 배포의 파일을 불러오기 위한 표시입니다.
