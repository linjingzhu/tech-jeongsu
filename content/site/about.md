# 사이트 소개

Jeongsu Tech Notes는 개발과 제품 기획, 운영을 하며 배운 것을 **구조와 근거가 있는 학습 문서**로 정리하는 개인 기술 노트입니다.

## 다루는 주제

| 섹션 | 질문 |
|---|---|
| AI 사용방법 | AI 에이전트를 실제 개발 과정에 어떻게 넣을 것인가? |
| Git 사용방법 | Git의 내부 구조와 협업 흐름을 어떻게 이해할 것인가? |
| AI Map | 어떤 AI 도구가 있고 어디에 적합한가? |
| 제품 기획과 운영 | Product Owner는 무엇을 판단하고 어떻게 일하는가? |
| Marketing | 제품을 고객에게 알리고 성과를 어떻게 측정하는가? |
| Platform 배포와 서비스 | 코드를 사용자에게 안전하게 배포하고 운영하려면 무엇이 필요한가? |
| 비즈니스 | 한국에서 소프트웨어 사업을 시작할 때 등록·법무·세무는 어떻게 준비하는가? |
| 1인 스튜디오 수익화 | 많이 만드는 1인 스튜디오는 무엇을 고르고 출시해 어떻게 수익을 내는가? |

## 문서를 만드는 방식

- **AI 도구와 함께 씁니다.** 초안 작성, 자료 조사, 번역에 AI 도구를 사용합니다. 이 사실을 숨기지 않습니다.
- **근거를 남깁니다.** 바뀔 수 있는 사실에는 날짜와 출처를 적고, 문서 끝의 참고 자료에 링크를 둡니다.
- **적대적으로 검토합니다.** 작성한 모델과 다른 모델이 범위, 깊이, 사례, 사실 정확성을 반박하는 방식으로 검토하고, 지적을 반영한 뒤 다시 검토합니다.
- **틀린 곳은 고칩니다.** 오류를 발견하면 문의 페이지의 방법으로 알려 주세요. 확인 후 수정합니다.

## 이용 시 유의사항

- 문서는 일반적인 학습 정보입니다. 특히 비즈니스 섹션은 법률·세무 자문이 아니므로, 실제 결정 전에 공식 기관이나 전문가에게 확인하세요.
- 도구 기능, 가격, 정책은 자주 바뀝니다. 각 문서의 기준일과 공식 출처를 함께 확인하세요.
- 외부 링크는 새 탭으로 열리며, 연결된 사이트의 내용은 해당 사이트의 책임입니다.

## 운영자

이 사이트는 Jeongsu가 운영합니다. 한국어와 영어 문서를 함께 제공하며, 영어 문서는 한국어 원문을 번역한 것입니다.
